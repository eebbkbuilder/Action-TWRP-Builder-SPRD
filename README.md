## Parameter Description

| Name                 | Description                                                        | Example                                                      |
| -------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------ |
| `MANIFEST_URL`       | Source address                                                     | https://github.com/minimal-manifest-twrp/platform_manifest_twrp_aosp.git |
| `MANIFEST_BRANCH`    | Source branch; `auto` reads a twrpdtgen-sprd tree                  | auto                                                         |
| `DEVICE_TREE_URL`    | Device tree address                                                | https://github.com/example/android_device_vendor_codename     |
| `DEVICE_TREE_BRANCH` | Device tree branch or tag                                          | main                                                         |
| `DEVICE_PATH`        | Device location; `auto` reads `DEVICE_PATH`                        | auto                                                         |
| `COMMON_TREE_URL`    | Optional common tree address                                       | https://github.com/TeamWin/android_device_asus_sm8250-common |
| `COMMON_PATH`        | Optional common tree location                                      | device/asus/sm8250-common                                    |
| `DEVICE_NAME`        | Output product name; `auto` reads `PRODUCT_DEVICE`                 | auto                                                         |
| `MAKEFILE_NAME`      | Product or full lunch target; `auto` preserves suffixes like ap2a  | auto                                                         |
| `BUILD_TARGET`       | `auto`, `boot`, `recovery`, or `vendorboot`                        | auto                                                         |

## twrpdtgen-sprd device trees

For a tree generated by
[weikaizhi4/twrpdtgen-sprd](https://github.com/weikaizhi4/twrpdtgen-sprd),
only `DEVICE_TREE_URL` normally needs to be changed. Leave the auto-detected
fields at `auto` and run **Recovery Build (SPRD)**. The Legacy workflow is for
pre-twrpdtgen Android 8.1-and-earlier trees.

The workflow reads the generated `README.md`, `BoardConfig.mk`, and
`AndroidProducts.mk` before syncing sources. It automatically selects:

- `twrp-12.1` and Java 11 for Android 13 and earlier;
- `twrp-14.1`, Java 17, and the `-ap2a` lunch target for Android 14 and newer;
- `vendorbootimage` and `vendor_boot.img` for a vendor_boot recovery tree;
- `bootimage` for an A/B recovery-as-boot tree;
- the source overlay under `prebuilt/sourcecode`, including its post-apply
  verification.

Any auto-detected value can still be replaced by an explicit workflow input.

## Setting up SSH Keys (optional)

#### 4. Go to Settings, then select Deploy keys and select "Add deploy key" button.

#### 5. On your Android device, install [Termux](https://github.com/termux/termux-app/releases)

#### 6. Install openssh in Termux and generate ssh keys. (Do not use passphrase for keys)

NOTE: When creating the deploy key for a repository like git@github.com:owner/repo.git or https://github.com/owner/repo, put that URL into the key comment. (Hint: Try ssh-keygen ... -C "git@github.com:owner/repo.git".)
owner = your Github username

```
pkg install openssh
ssh-keygen -t ed25519 -C "git@github.com:owner/Action-Recovery-Builder.git"
```

#### 7. Add the keys to your repo. In Termux, use the following commands:

```
cd /data/data/com.termux/files/usr/etc/ssh
cat ssh_host_ed25519_key.pub
```

  Select and copy the key then paste in the box for Key.
  You can name it whatever you choose for the title.

#### 8. Now to add your private ssh key. Back in Termux:

```
cat ssh_host_ed25519_key
```

   Copy the output from Termux.

   In your browser, select *Secrets* under the Security tab.
   Select Actions
   Select New repository secret
   For the New secret name, it should be SSH_PRIVATE_KEY
   Paste the output from ssh_host_ed25519_key into the Value box.
   Then select Add secret.
